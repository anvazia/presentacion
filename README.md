# Presentación de Andy

Diaporama animado «¡Hola, soy Andy!» para mis clases de español.

Abrir: https://anvazia.github.io/presentacion/

Teclas: → / espacio avanzan, ← retrocede, F pantalla completa, N notas. Tocar una foto o un vídeo la abre en grande.

Créditos: emojis 3D de Brixmoji (brixmoji.com); fotos de lugares de Wikimedia Commons, Pixabay, Pexels y otras fuentes, solo para uso en clase; algunas imágenes de Andy hechas con IA.
